# Upstream

Gromozeka Browser Bridge was derived from `packages/extension` in Playwright:

- Repository: https://github.com/microsoft/playwright
- Source commit: `1720c55cfaddfb01a5bb4c9ddf43e42053811a25`
- Upstream license: Apache License 2.0

The Gromozeka fork changes the connection scope from one Chrome tab group to
all ordinary tabs in the browser profile, removes tab-group manipulation and
focus changes, and replaces the Playwright branding and installation UI.
